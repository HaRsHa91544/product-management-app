# Product Management App

This project started as a React practice app and grew into a full stack app with a backend. It was built to strengthen React skills while adding the server-side logic needed to manage real product data.

The app allows users to add, edit, delete, and view products. It includes search and category filtering, form validation, and duplicate ID checks to keep the product list consistent. The frontend is built with React and Vite, while the backend uses Express and MongoDB to handle product data through API routes.

## Stack

- React
- Vite
- JavaScript
- Express
- MongoDB
- Mongoose

## Run locally

Frontend:
```bash
cd client
npm install
npm run dev
```

Backend:
```bash
cd server
npm install
npm run dev
```

This project reflects the transition from a frontend learning app into a complete product management system with both client and server responsibilities.
